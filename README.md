# 🌦️ Weather App

## Project Overview

Weather App is a Python desktop application built using Tkinter. It allows users to enter a city name and retrieve real-time weather information using the Open-Meteo Geocoding and Forecast APIs.

The application converts the city name into geographic coordinates and then fetches current weather information for that location.

---

## Features

* Search weather by city name
* Real-time weather information
* Temperature display
* Humidity display
* Wind speed display
* Atmospheric pressure display
* Weather condition display
* User-friendly Tkinter GUI
* Invalid city detection
* Network error handling
* API error handling

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

python weather.py

5. Enter a city name and click Search.

---

## How It Works

1. User enters a city name.
2. Open-Meteo Geocoding API converts the city into latitude and longitude.
3. Open-Meteo Forecast API retrieves current weather information.
4. The weather report is displayed in the GUI.
5. Errors are handled gracefully and shown to the user.
